The Problem

Bangladesh's essential commodity markets suffer from structural information asymmetry.

📈
Price Opacity
DAM bulletins published irregularly; no unified data feed.
🌐
Fragmented Sources
Government bulletins, retail apps, and field reports use incompatible labels.
🔍
No Early Warning
Supply shocks go undetected until they reach retail — too late for intervention.
Research Question: Can a unified, offline-first intelligence system reliably normalize heterogeneous commodity data and detect market anomalies before they impact consumers?

Objectives

O1 Bilingual Normalization Engine

Unicode NFKC + alias taxonomy resolving Bengali/English commodity labels and regional units (maund, hali, seer) to SI-canonical form.

O2 Multi-Source Realtime Ingestion

DAM government bulletin harvesting + Chaldal retail parsing with automated fallback resilience.

O3 Explainable Anomaly Detection

Rolling SMA + Z-score + CV compound rule with auditable natural language justification. Zero black-box ML — every flag is mathematically reproducible.

O4 Web + Android REST API

FastAPI JSON gateway serving React web dashboard and Android Jetpack Compose client.

System Architecture

Five-layer decoupled design — local-first, offline-capable.

📱 Presentation — React 18 / Jetpack Compose
🔌 API Gateway — FastAPI + Pydantic v2
⚙️ Service Layer — Normalizer · Anomaly Engine · Confidence Scorer
📡 Collectors — DAM Live · Chaldal Live · Fallback Fixtures
🗄️ Persistence — SQLite WAL · SQLAlchemy ORM
Key Design Decisions
✦ SQLite WAL — concurrent read/write without server process
✦ In-process asyncio scheduler — no Redis/Celery dependency
✦ Fixture fallback — collectors degrade gracefully on network failure
✦ Pure JSON REST — identical API for Web and Android
✦ No internet required for demo or evaluation

Statistical Anomaly Detection

Compound Decision Rule — both conditions must hold to prevent false alerts.

SMA Baseline
SMA₁₄ = (1/n) Σ Pᵢ
Z-Score
Z = (P_current − SMA₁₄) / σ
Volatility (CV)
CV = (σ / SMA) × 100%
Compound Trigger:   |Z| ≥ threshold AND |Δ%| ≥ threshold

Severity|Z| ≥|Δ%| ≥
Moderate1.510%
Severe2.020%
Critical2.530%
Onion Shock Day 30:   Price 98 BDT/kg  |  Z = +17.98  |  Δ% = +50.3%  |  CRITICAL SPIKE

Anticipated Viva Questions

Q: Why not use ML for normalization?

Alias taxonomy is deterministic, auditable, and zero-shot for new commodities — just add an entry. ML models require labeled corpora that don't exist for BD regional dialects.

Q: Why SQLite instead of PostgreSQL?

WAL mode enables concurrent reads with a single writer — sufficient for district-level deployments. Zero infrastructure: no server process, embedded in the application binary.

Q: How do you prevent outlier poisoning from field reports?

Tier 4 confidence dampener (0.60 base weight). Anomaly engine weights by confidence score. Administrators can approve reports to upgrade source tier.

Q: What is the Z-score threshold and why?

1.5σ for Moderate (covers ~87% of normal distribution), 2.5σ for Critical (covers ~99%). Compound rule (Z AND Δ%) eliminates false alerts during high-volatility regimes.
